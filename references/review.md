# 看片和修改

## 每一版交给用户之前，自己先查

```bash
python3 <skill>/scripts/contact_sheet.py mv-r1.mp4 --every 0.5 -o review/r1-sheet.jpg               # 全片每 0.5 秒一格，自己看一遍
python3 <skill>/scripts/contact_sheet.py mv-r1.mp4 --srt lyrics.srt -o review/r1-lyrics.jpg          # 每句歌词刚出来时的画面，格子下面是这句该是什么
python3 <skill>/scripts/video_rhythm.py mv-r1.mp4 --analysis song-analysis.json                      # 切点、不动的段、黑帧、卡不卡拍
python3 <skill>/scripts/contact_sheet.py mv-r1.mp4 --every 0.1 --start 31.4 --end 32.6 -o review/r1-cut-32.jpg   # 每个转场前后 ±0.6 秒逐帧
```

要过的线：
- 没有连着 1 秒以上几乎不动的段（故意停住的一拍除外）
- 切点都是你打算切的地方；转场是有衔接的（逐帧条里看得出东西是动过去的）
- 没有黑帧；第一帧、最后一帧不是一片空白或纯黑
- 每句歌词出来时，画面演的就是这句
- 角色的脸、手、道具没被歌词挡住，远处的东西没被挡住
- 成片响度和原曲差 1 dB 以内（`finalize_audio.py` 打印的）

你看不了视频：节奏和动静以脚本量出来的数为准，不凭感觉说「已经很流畅」。告诉用户这一版的结果时，说清楚哪些量过、哪些你拿不准。

## 最常见的 5 个毛病

用户说了下面这些，照「怎么改」做；用户截图说「看到哪个毛病就发这句」，用的就是「发给 agent 的话」那一列。

| 毛病 | 发给 agent 的话 | 怎么查、怎么改 |
|---|---|---|
| 像幻灯片 | 画面动态不足，像幻灯片。先用 ffmpeg 每 0.5 秒抽帧、计算相邻帧差，找出静止段落，再让角色持续有动作、镜头保持缓慢运动，每句歌词安排一个清晰的主要动作，以中近景呈现。 | `video_rhythm.py` 的「几乎不动的段」；角色一直有动作（呼吸、走、反应），姿势之间补间，镜头一直在慢慢动，世界里有东西在动 |
| 运镜晃 | 镜头运动过于频繁。每个镜头只保留一种缓慢运动：慢推、慢移或跟随角色。 | 0.25 秒一格的接触表看构图是不是一直在跳；去掉来回推拉、拍子缩放、旋转；一段最多一次远近变化 |
| 表现力不够 | 情绪表现不足。情绪最强的段落改用近景，光线与色调随情绪变化。 | 情绪点角色占画面 35–50%；反应放大（吃惊、跳、塌下去）；按段加整体色调和光 |
| 道具不对 | 手持道具位置异常。道具须贴合手部，且不得遮挡面部。 | 道具按 `handAt()` 画；逐帧条看手、道具、脸的位置关系；物件照真实的样子动（船在水上划，不从天上飞） |
| 歌词没演出来 | 「（这句歌词）」的画面未能表达歌词含义，请换一种更直观的表现方式。 | 先问用户这句想表达什么；照 `storyboard.md` 的规矩重新想这句（拆成几步、用身体演、不靠小道具）；整体看不懂就回第 4 步重写故事 |

## 其他常见的

| 毛病 | 怎么改 |
|---|---|
| 东西凭空消失又出现、角色瞬移 | 照 `transitions.md`「不管哪种都要做到」：前后帧接上、出画入画方向对上、消失要演出来 |
| 硬切、整屏叠化看着僵 | 换成推拉、甩镜、前景扫过、画面里的东西自己变 |
| 歌词对不上 | `--srt` 那张接触表找出偏的那几句；时间以 `lyrics.srt` 为准，错了让用户改 srt 再重转 `lyrics.js` |
| 声音变小了 | `finalize_audio.py` |
| 某段拖沓 | 过场一个画面不超过 2 秒左右，里面要有一件看得懂的事 |

## 改的规矩

- 每改一版存一个新文件（`mv-r2.mp4`…），旧的留着；告诉用户改了什么、在哪几秒
- 只重渲改过的段（路线 B：`render_frames.mjs --from --to --force`）
- 每一版都重跑上面的自检
- 用户说「看不出 X」：先问清楚是表现方式不够直观，还是剧情本身不对。剧情不对就回第 4 步整个重写
