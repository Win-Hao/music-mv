# 转场

先定整片的骨架（主方案），再给每一处转场挑手法：主方案让整片统一，手法跟着歌变。根据画风和歌的节奏选一个主方案，主方案和理由写在 `storyboard.md` 开头，再在分镜表最后一列给每两个相邻镜头写明用哪种手法、卡在哪一拍，和分镜一起给用户确认（不单独停一次）。用户已经说了要哪种，就直接用。

## 整片的主方案

**1. 一镜到底**：整片是同一个世界，一台虚拟摄像机连续拍
- 换地方：镜头往上摇进天空，在只剩天的那几帧换场景；推进窗户、门；角色跳进门、门关上
- 换季、换时间：让画面里的东西自己演（树长叶落叶、雪化、太阳落下、一阵风卷着花瓣扫过），不叠化
- 两个角色的戏写成几段连续的表演，每个镜头只是换个机位拍
- 适合：抒情、讲故事的歌

**2. 卡点切换**：在拍点上换镜头，用有衔接的切接起来
- 甩镜、遮挡物扫过、形状匹配、动作接动作、闪白（见下面的手法）
- 适合：节奏明显、副歌有力的歌

**3. 拼贴快切**：一张张拼贴画面快速换
- 新画面像卡片一样滑进来（0.15–0.3 秒，挪动那几张糊出一小段拖影，卡边另外清楚地贴一次）、撕开、翻页、拉幕、从画框里拉出来（`examples/collage/scene.html` 有滑进、撕开、翻页三种）
- 画面一层层搭起来：东西卡着拍子从下面升上来、从上面掉下来
- 能看清的画面一般停 0.7–3 秒（一支参考片里逐帧量出来的：短了看不清，长了像幻灯片，按歌速调）；短于 0.5 秒的只用在转场本身和个别快切组（每张一个主体占满画面）
- 每张画面都是故事的下一步，不是贴上去的装饰；同一张图不重复用
- 适合：快歌、想要拼贴感的

**4. 嵌套缩放**：每个场景都藏在上一个场景里，一路推进去或者一路拉出来
- 推进窗户、照片、眼睛、一滴露水，里面是下一个场景；或者从一张长椅一路拉到整个地球，再推回来
- 每一层的「窗」先放到画面正中再推，推的倍数用对数插值（见「在代码里怎么接」）
- 适合：讲一个人和整个世界、一件小事和很大的心情、回忆一层套一层

**5. 原地看时间走**：机位几乎不动，同一个地方，时间往前走
- 同一张长椅、同一扇窗：春夏秋冬、白天黑夜、从小到老。卡在拍上一步步变，变的是光、天气、季节、人
- 镜头只做很慢的一种动作，故事全靠变化本身
- 适合：陪伴、等待、时间、一个地方的回忆

**6. 舞台、书、老胶片**：整片是一个画框里的东西，换场靠画框自己
- 一本书（翻页、折起来弹出来）、一个舞台（拉幕、换布景、灯一暗一亮）、一卷老电影（收光、跳帧）
- 适合：童话、民间故事、复古的歌；配绘本、立体书、皮影戏、橡皮管卡通画风

**7. 分格、分屏**：画面分成几格，几条线同时演
- 两个人在两个地方、对唱、过去和现在。格线卡着拍一条条画出来；格子合并、裂开、一格放大成全屏就是转场
- 两格之间可以有一条线接着（同一条地平线、同一张桌子、两个人伸向对方的手），看着像一个画面裂成两半
- 适合：两个人的歌、对唱、对比

主方案定一个，段落交界、最重的几下、突然安静的地方可以借别的手法（见「按歌里的位置挑」）。同一种手法连着用，第三次就没感觉了，换着来。

## 转场手法

### 藏起来的切：看不出切了

- **甩镜**（whip pan / whip tilt）：镜头横甩或竖甩 0.3–0.5 秒，带动态模糊，在最糊的那一帧换地方。两处地方画在同一个世界里、中间那段也画出来，不露画面边；前后甩的方向、速度接得上
- **遮挡物扫过**：镜头不动，东西从镜头前扫过去（风卷的花瓣、落叶、一堵墙、走过的人、伸过来的手、飞过的鸟），挡住的地方换成新镜头；分界藏在遮挡物里，羽化收窄到 100 px 左右，太宽像重影
- **镜头掠过遮挡物**：东西不动，镜头横移经过一根柱子、一棵树、一个背影，被挡住时换；前后两个场景各有一样相似的遮挡物最好
- **钻进黑暗**：镜头推进一片阴影、一个洞口、一件黑衣服，全黑的那一下换，从另一片黑里出来
- **云、雾、烟、雪扑满画面**：镜头飞进云里，或者一阵烟、一阵大雪扑过来，白茫茫的那一下换

### 镜头带过去

- **穿越推进**（push through / object portal）：推进窗户、门、钥匙孔、眼睛、照片、手机屏幕、镜子、雪景球，推到它占满画面，就进了里面的世界
- **拉远揭示**（pull-out reveal）：拉开才发现刚才是一张画、一张照片、一个屏幕、一个倒影、一个人的梦
- **无限缩放**（earth zoom）：从长椅一路拉到整个地球再推回来，或者一路推进一滴露水里的另一个世界
- **摇进天空、低头看地**（tilt）：镜头往上摇到只剩天，或者往下摇到只剩地面、水面，在那几帧换场景
- **穿墙、穿地板**（pass through）：镜头横移穿过一面墙到隔壁，往下穿过地板到楼下，像剖开的娃娃屋；立体书画风最合适
- **跟着东西走**：一只纸飞机、一个气球、一片花瓣、一只鸟从这个场景飞出去，镜头跟着它，它落进下一个场景
- **希区柯克变焦**（dolly zoom）：人物大小不变，身后的世界忽然拉远或者压过来。用在「突然明白了」「愣住了」的那一句，整片一次

### 看得出切了，但有东西接上

- **形状匹配**（match cut / graphic match）：切的那一帧，同一个位置有大小差不多的形状：月亮 → 盘子，眼睛 → 地球，雪花 → 花
- **动作接动作**（match on action）：动作在上一个镜头开始、下一个镜头完成：扔出去的球在另一个地方落下，推开的门通到另一个季节。切在动作进行到三分之一左右
- **同一个动作两个时空**（match motion）：小时候和长大以后做同一个动作（伸手、转身、打响指），动作对齐着切
- **视线接**（eyeline / POV）：角色抬头看向画外，切到他看见的东西
- **三连跳近**（axial cut / punch-in）：同一个角度，卡在连着的三下重音上一下比一下近：全身 → 半身 → 脸
- **跳切**（jump cut）：同一个机位，每一拍时间往前跳一截：衣服换了、季节换了、人老了
- **猛切**（smash cut）：从很静的画面直接切到很满、很亮的画面，正好落在副歌进来、drop 的那一拍；前面越静越好
- **闪白**（flash cut）：最重的一下画面亮起来，在最亮的那一帧换。光最好是画面里来的：闪电、烟花、相机闪光灯、车灯、开灯
- **交叉剪辑**（cross-cutting）：两条线来回切（两个人在两个城市），每次切都用形状、动作或视线接上，越到后面切得越快，最后汇到一个画面里

### 画面里的东西自己变

- **场景改写**（set transition）：镜头不动，墙倒下去变成地面、家具滑走、纸片翻面，房间变成另一个地方；角色一直在画面里
- **变形**（morph）：一样东西变成另一样：心变成气球、雪花变成花瓣、门变成书页。形状、颜色、大小一起过渡
- **原地换时间**：同一个地方，树长叶落叶、雪化、天黑了灯亮了，卡在拍上一步步变
- **灯光换场**：灯灭了全黑，再亮已经是另一个地方；或者一束光扫到哪里，哪里就变成新的场景
- **眨眼**（blink）：上下两条弧线合拢像闭眼，睁开是另一个地方：梦、回忆、醒来
- **散开再拼起来**（particles）：画面碎成花瓣、雪、萤火虫，飞起来再拼成下一个画面；碎和拼都卡拍
- **倒影翻上来**：低头看水坑、镜子、窗玻璃，倒影里的世界翻上来变成正面
- **剪影里的回忆**（double exposure）：人的剪影里透出另一个画面（回忆、想念的人）。只在剪影、形状里叠，不整屏叠化

### 画框、画材：画风自带的，优先用

- **翻页**（page turn）：绘本、蜡笔、拼贴。一页翻过去露出下一页，翻起来的那页背面有纸色和阴影
- **撕开、揭开**（paper tear / sticker peel）：拼贴。撕开一张纸、揭掉一张贴纸，下面是下一个画面；撕口露白色纸纤维
- **折起来、弹出来**：立体书。这一页的场景折倒，下一页的弹起来
- **墨晕开、提白**：水墨。一团墨洇开盖住画面，再提走露出下一张
- **换一套色版、辊子刷过**：浮世绘、孔版印刷。新的一版从一边刷过去，刷到哪变到哪
- **收光**（iris）：橡皮管卡通、默片。圆缩成一个针孔（不收到全黑，圈外用画风里最深的颜色），再从新画面里张开；可以先收到角色脸上停一拍，让它冲镜头眨眼（心形、星形更俗，少用）
- **灯一暗一亮换一幕**：皮影戏
- **线变形**：一笔画。线从这个画面的形状拉成下一个画面的（`examples/one-line/scene.html`：一片花瓣按弧长变成鸟，再跟着鸟推出窗外）
- **像素转场**：像素风。马赛克变粗再变细、按抖动点阵一格格换、老游戏里的百叶窗和螺旋
- **画幅变化**（ratio switch）：4:3 的画面在副歌打开成 16:9，或者回忆收成窄窄的一条；画面不拉伸，是露出更多或者裁掉
- **胶片烧穿、跳帧**：老胶片。画面中间烧出一个洞，或者片子跳一下接到下一卷
- **故障、漏光**：像素风可以故障一下（错位、色彩分离），胶片风可以漏光。只跟着画风用

### 时间：变速、定格

- **变速**（speed ramp）：关键的一瞬慢下来（跳起来、回头、花瓣落下），转场时再快过去
- **定格**：突然安静的那一拍画面停住，留一两样东西还在动（雪、头发、纸纹），声音回来时一起放开
- **倒放**：时间倒流、回到过去；整片一次
- **卡顿重复**：歌里有重复的字、切分的节奏时，同一个小动作重复两三下

## 按歌里的位置挑

转场放在哪、用哪种，从 `song-analysis.json` 来（拍点、段落、突变点、最重的几下）：

| 歌里的位置 | 适合的手法 |
|---|---|
| 主歌里、两句之间 | 跟着东西走、动作接动作、镜头带过去：慢、连着，不抢歌词 |
| 鼓点、每小节第一拍 | 甩镜、形状匹配、跳切、卡片卡拍落下 |
| 副歌进来、drop | 猛切、穿越推进到底、三连跳近、画幅打开 |
| 突然安静、低音撤掉 | 定格、慢动作、收光到只剩一束光、灯灭 |
| 低音重新进来 | 灯亮、碎掉的东西拼回来、画面重新动起来 |
| 最重的几下 | 闪白、换一套色版、整个画面一震 |
| 段落交界（主歌进副歌） | 换季换时间、穿过窗户、翻页、拉远揭示 |
| 回忆、梦、想象 | 眨眼、推进照片、倒影翻上来、剪影里的回忆 |
| 两个人、两个地方 | 分格、交叉剪辑、东西从一个人那里飞到另一个人那里 |
| 结尾 | 拉到很远、收光、合上书、回到开头的画面（首尾呼应） |

## 不管哪种都要做到

- 每次转场都有衔接，起点对齐拍子，接着角色的动作或画面里的东西
- 前一个镜头最后一帧的角色大小、位置、姿势 = 后一个镜头第一帧的，不瞬移。要换位置就让角色自己挪过去
- 角色从哪边出画，就从对应的那边入画，中间不空帧
- 镜头推拉时画面里的东西不凭空消失、不凭空出现。拉远用好几张背景接力时，每张画的东西要一致；要让东西消失就演出来（化成花瓣飘走）
- 不做没有衔接的硬切，不整屏叠化，不用生硬的扫光条：以前的片子里这三种看着最僵。看得出的切要有东西接上（形状、动作、视线），或者正好落在歌里的突变上

## 在代码里怎么接

转场不是两段视频中间加一个效果，是同一个页面里两个镜头在那几拍一起画、顺着同一条镜头曲线接过去。拼片段接不出来，所以整支 MV 写在一个页面里。

```js
// 第 16 拍上从天台甩到街口：拍前 0.4 秒起步加速，拍上落位；慢移和甩镜叠在一条曲线上
const T0 = MV.beatTime(16) - 0.4, T1 = MV.beatTime(16);
const camX = (t) => ROOF.x + 30 * t + (STREET.x - ROOF.x) * MV.ease.inOut(MV.seg(t, T0, T1));
```

- **两个镜头都画**：转场那几拍，前一个镜头还在画，后一个镜头已经开始画（`SHOTS` 的起止前后多留出转场的长度），按转场方式决定谁挡住谁。只画一边就只能硬切
- **起点在拍前，落点在拍上**：动作在拍点前 0.2–0.5 秒起步、加速，在拍点上落位（`MV.beatTime(n)`、`SONG.downbeats`、`SONG.events` 的突变点、`SONG.hits` 最重的几下）。落点卡拍，看的人才觉得踩上了
- **不用匀速**：位置用 `MV.ease.inOut`（甩镜、推进）、`MV.ease.out`（东西落下、滑进来）；落位可以冲过一点再回来（`MV.ease.back`、`MV.ease.spring`）。匀速插值起停都是一下子，像幻灯片换页。`ease.out` 走到六成时间，位置已经到了九成多，看着像提前落位：要卡在拍上，就把它的终点往拍后挪 0.1–0.15 秒，或者改用 `inOut`
- **速度连续**：镜头的慢移和转场的大动作叠在同一条曲线上（上面的 `camX`），不要先停住再起步；转场完镜头接着刚才的方向慢慢走
- **甩镜开动态模糊**：`blur(t)` 按镜头这一帧走了多少像素给子帧数（见 `render.md`）
- **一直在动**：转场前后两个镜头里的东西都在动（雪、光点、角色呼吸），换过去以后接着动，没有一帧是冻住的
- **自己查**：每个转场落点前后 0.6 秒，每 0.1 秒一张拼成一排看：位置连续、没有空帧、落位那一帧正好在拍上。整片渲好后用 `contact_sheet.py render.mp4 --around <落点,落点…> -o review/trans.jpg`（落点就是 `render_frames.mjs` 打印的「页面的转场落点」）；还没渲整片时，`render_frames.mjs --times` 出这几张，`contact_sheet.py --images <目录> --cols 13` 拼起来

### 常用写法

模板 `templates/mv/index.html` 已经搭好了骨架：镜头表 `SHOTS` 里相邻两个镜头的时间重叠一段，重叠的那几拍调 `transition(g, t, a, b)`（模板里是一阵大雪扫过），下面的写法都是往这个函数里填的。`kit.js` 里有 `MV.reveal`（在遮罩里画另一个镜头）、`MV.blob`（不规则的圆）、`MV.morph`（变形）、`MV.lerpLog`（对数插值）、`MV.retime`（变速）。下面的 `drawA`、`drawB` 是两个镜头的画法（就是 `a.draw`、`b.draw`），里面只用 `translate`、`scale`、`rotate` 套自己的镜头，用 `save`/`restore` 包好，不用 `setTransform`（会把外面的缩放冲掉）。`u` 是转场进度 0 → 1，一般是 `MV.ease.inOut(MV.seg(t, 起, 落))`，落点在拍上。

**遮罩**：扫过、撕开、收光、墨晕开都是「先画 A，再在遮罩里画 B」，区别只在遮罩的形状。

```js
drawA(g, t);
MV.reveal(g, (m) => m.rect(-200, -200, 200 + (W + 400) * u, H + 400), (m) => drawB(m, t), 100);  // 从左往右扫过，羽化 100 px，遮罩伸出画面外
MV.reveal(g, (m) => MV.blob(m, W / 2, H / 2, 1400 * u, 'ink-3', 0.2), (m) => drawB(m, t));        // 不规则的圆：墨晕开、水渍、撕开的洞
// 收光：先铺一层深色（画风里最深的那个颜色，不用纯黑），前半段圆缩小露 A，后半段圆张开露 B。
// 收到一个小针孔就换镜头，不收到 0：整帧全黑会被 video_rhythm 量成黑帧，看着也像断片
g.fillStyle = DARK; g.fillRect(0, 0, W, H);
MV.reveal(g, (m) => m.arc(cx, cy, Math.max(16, Math.hypot(W, H) * Math.abs(1 - 2 * u)), 0, Math.PI * 2), (m) => (u < 0.5 ? drawA : drawB)(m, t));
```

遮挡物扫过时，遮罩就是遮挡物的轮廓（花瓣群、墙、人的剪影）扫过的范围。`draw` 是 async 的（p5.brush）就 `await MV.reveal(…)`，写法见 `templates/mv/p5brush.html` 的 `transition`。

**眨眼**：上下两片带弧度的眼皮合上再张开，合上前画 A、张开时画 B；眼皮边可以用 `g.filter = 'blur(…)'` 糊一点。

```js
const bow = H * 0.2, c = (H / 2 + bow) * (1 - Math.abs(1 - 2 * u));   // c：眼皮盖到哪，u = 0.5 时全合上
(u < 0.5 ? drawA : drawB)(g, t);
g.fillStyle = DARK;                                                    // 眼皮用画风里最深的颜色，合上那一两帧不是纯黑
g.beginPath(); g.moveTo(-10, -10); g.lineTo(W + 10, -10); g.lineTo(W + 10, c); g.quadraticCurveTo(W / 2, c - 2 * bow, -10, c); g.fill();
g.beginPath(); g.moveTo(-10, H + 10); g.lineTo(W + 10, H + 10); g.lineTo(W + 10, H - c); g.quadraticCurveTo(W / 2, H - c + 2 * bow, -10, H - c); g.fill();
```

**穿越推进**：B 画在 A 里的一扇「窗」里（窗户、照片、屏幕、一只眼睛），用 `MV.pushInto`：窗在 A 画面上的哪儿都行（不用先挪到正中），宽高比也不用和画面一样；镜头绕一个不动点按对数推进去，推到 `u = 1` 时窗正好盖满画面、画面就是 B（实测和直接画 B 逐像素一样），之后只画 B 就接得上。拉远揭示就是倒过来（`u` 从 1 走到 0），无限缩放就是一层套一层。

```js
const win = { x: 1180, y: 300, w: 420, h: 260 };          // 窗在 A 画面上的位置（照片、眼睛……）
MV.pushInto(g, win, ease.inOut(seg(t, T0, T1)), (m) => drawA(m, t), (m) => drawB(m, t));   // T1 落在拍上
```

别自己写成「绕画面中心放大、窗再平移过去」：窗不在正中时推到底盖不满（做过：推进转场落位时画面边上还露着一条 A），平移和放大分开插值镜头还会走弧线。

p5.brush 画风别这么推：`g.scale` 放大的是从 p5 拷过来的位图，推到底会糊。让 A 的镜头 `cam(t)` 的 `z` 跟着放大、在 p5 里重画，B 照常拷过来缩进窗里。

**分格**：每格是开在一个镜头上的窗，镜头的中心对准格子的中心；格子放大到全屏，就是这个镜头本身。

```js
function panel(g, t, r, drawShot) {                       // r = { x, y, w, h }：这一格在画面上的位置
  g.save(); g.beginPath(); g.rect(r.x, r.y, r.w, r.h); g.clip();
  g.translate(r.x + r.w / 2 - W / 2, r.y + r.h / 2 - H / 2);
  drawShot(g, t); g.restore();
  g.strokeStyle = '#111'; g.lineWidth = 10; g.strokeRect(r.x, r.y, r.w, r.h);   // 格线
}
```

**变形**：两个形状写成点列 `[[x, y], …]`，点数、绕的方向不用一样，`MV.morph` 会按长度重新取点、对齐起点。

```js
const pts = MV.morph(heart, balloon, u);
g.beginPath(); pts.forEach(([x, y], i) => (i ? g.lineTo(x, y) : g.moveTo(x, y))); g.closePath(); g.fill();
```

**变速、定格**：给这个镜头一条速度曲线（1 正常、0.2 慢放、0 定格），镜头用自己的时间画；雪、呼吸这种一直在动的东西仍用 `t`。慢放过后，这个镜头里的动作会比歌晚一截：卡拍的动作按真实的 `t` 排，或者在下一个转场处换镜头。

```js
const speed = (t) => 1 - 0.8 * MV.ease.smooth(MV.seg(t, 12.4, 12.7)) * (1 - MV.ease.smooth(MV.seg(t, 13.3, 13.6)));  // 12.7–13.3 秒慢到 0.2 倍
drawShot(g, 12 + MV.retime(t, 12, speed));               // 这个镜头从 12 秒开始
```

**闪白**：2–3 帧亮起来，在最亮那一帧换镜头，0.2–0.4 秒退掉。

```js
const flash = (t, at) => (t < at - 3 / FPS ? 0 : t < at ? MV.seg(t, at - 3 / FPS, at) : Math.exp(-(t - at) / 0.12));
(t < HIT ? drawA : drawB)(g, t);
g.globalCompositeOperation = 'lighter'; g.fillStyle = `rgba(255,248,230,${0.95 * flash(t, HIT)})`; g.fillRect(0, 0, W, H); g.globalCompositeOperation = 'source-over';
```

**像素风的抖动溶解**：在小画布上按 4×4 抖动表一格格换成 B，每个像素要么是 A 要么是 B，不是半透明叠化。整屏均匀地溶看着还是像叠化，最好让它有方向：从 B 的主体（比如近景里角色的脸）往外一格格翻开，`examples/pixel/scene.html` 用的是 16×16 的菱形格子。

```js
const BAYER = [0, 8, 2, 10, 12, 4, 14, 6, 3, 11, 1, 9, 15, 7, 13, 5], n = Math.floor(u * 17);
for (let y = 0, i = 0; y < LH; y++) for (let x = 0; x < LW; x++, i += 4) {   // a、b、o：同样大小的 ImageData
  const s = BAYER[(y & 3) * 4 + (x & 3)] < n ? b : a;
  o.data[i] = s.data[i]; o.data[i + 1] = s.data[i + 1]; o.data[i + 2] = s.data[i + 2]; o.data[i + 3] = 255;
}
```

## 运镜

以前的片子被说过「一会儿推一会儿拉，看着头晕」，所以一个镜头里要稳；转场时的大动作另算。

- 一个镜头里只做一种慢动作：慢推、慢移、或者跟着角色走，一个方向走到底
- 一个镜头里远近变化最多一次，一般幅度小（比如 1.0 → 1.08）；情绪点要推到近景时可以推得多，但要慢、一个方向、不回拉
- 镜头里不来回推拉，不左右来回摇，不每拍缩放，不转；漂移只留几个像素
- 转场时的大动作不受上面几条限制，但分清两种：一镜到底里换地方（抬进天空、推进窗户）放慢到 1 秒左右；卡点切换的甩镜是快的，0.3–0.5 秒，带动态模糊，落在拍上
- 只在最重的几下（`SONG.hits`、突变点）轻轻顿一下：放大 2–3% 再回落，不是每拍都顿
- 旋转只当转场用，整片一两次（世界翻过来、掉进梦里），半秒内转完、带动态模糊
- 「画面一直在动」靠角色和世界里的东西（雪、雨、叶子、光点、云），不靠镜头晃
- 竖屏横向窄：换地方多用上下摇（往上摇进天空、往下摇到水面）和推拉，少用横甩
