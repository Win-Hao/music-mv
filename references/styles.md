# 画风

## 选画风的规矩

- 按 song.md 的情绪挑 3 种，**同一个开场画面**各画一张 1920×1080 样图，放 `styles/`，每张附一句为什么适合这首歌。停，等用户选
- **每种风格从头用它自己的画法画**：像素风在小画布上逐像素画，拼贴是一张张纸片拼的，蜡笔是一笔笔画的。不要先画好一张，再给它加像素化、纸纹、描边这类滤镜冒充别的风格：构图、物件、光影一模一样，一眼就看得出是滤镜。角色和道具也按这个风格重新画（像素风画 sprite，拼贴做纸偶）
- 交之前问自己：这像不像一个专门做这种风格的人做的原生作品？
- 四种风格都有原生的示范代码，在 `examples/<风格>/scene.html`（同一段 5 秒的小螃蟹雪夜，可以直接读代码学画法）
- 只选代码画得好的。写实人脸、3D 质感、真实光影是视频生成模型的活，这个 skill 不做
- 不要：深色底配霓虹光、紫色渐变、渐变色团、整屏文字。一屏只留一个强调色
- 选定后把画法写进 song.md 的「画风」一节：5–8 个颜色（HEX）、线条、纹理、动起来的手感（每秒换几张、抖多少）、歌词放哪、什么样。后面每个镜头照这一节画

## 1. 像素游戏风

- **像什么**：老游戏机画面。歌词进游戏的对话框，画面里有血条、任务栏这类小 UI
- **画法**：Canvas 2D。在 320×180 的小画布上逐格画（4:3 用 320×240），整片限定 16–32 色的一套调色板；渐变用抖动点阵（ordered dithering），不用平滑渐变。画完整数倍放大到成片（×6 = 1920×1080），放大时 `ctx.imageSmoothingEnabled = false`
- **动起来**：角色逐帧换画（走路 4 帧、跳 3 帧），不做补间；镜头按整像素移动；背景分几层做视差
- **歌词**：像素字放进对话框，打字机一样一个字一个字出
- **适合**：轻快、怀旧、俏皮的歌
- **坑**：字、线都在小画布上画完再放大，放大之后再画会糊；字用像素字体（中文可以用开源的缝合像素字体 Fusion Pixel），在小画布上画完把透明度二值化成硬像素
- **不是**：高清图缩小再放大、马赛克滤镜。那样颜色数不受控、边缘发糊、没有抖动点阵
- 示范：`examples/pixel/scene.html`

## 2. 纸艺拼贴绘本

- **像什么**：剪纸、撕纸贴出来的绘本。歌词贴在纸条上
- **画法**：每个元素是一张纸片。外面一圈剪纸白边（或撕纸毛边），下面垫一点投影，一层层叠放；底纹用旧报纸、牛皮纸、方格纸（代码生成噪声和纤维线）；胶带、订书钉、手写字做点缀
  - 白边：把元素的透明图 alpha 往外扩 6–10 px，填暖白（如 `#FFF9EE`），阴影垫在白边下面、不描边
- **动起来**：画面每秒只更新 8–12 次，每次每张纸片随机抖 1–2 像素（种子用「元素名 + 第几张」，像定格动画）；东西卡着拍子从下面升上来、从上面掉下来；新画面像卡片一样滑进来、刷开
- **歌词**：贴在纸条上，纸条卡着拍子贴上去
- **适合**：快歌、情绪变化多、想快切的歌
- **不是**：一张普通插画上叠一层纸纹、加一圈白描边。每个元素都要是单独的纸片（自己的纸质、自己的边、自己的影子）
- 示范：`examples/collage/scene.html`

## 3. 蜡笔手绘 / 水彩绘本（扁平绘本）

- **像什么**：儿童绘本。蜡笔、铅笔或水彩的笔触，看得见纸纹
- **画法**：p5.js（v2，实例模式）+ p5.brush。线条用铅笔、蜡笔、炭笔笔刷，有轻重和颗粒；**蜡笔**的填色用排线（`brush.hatch()` / `setHatch()`，来回两三层、每块角度略不同），**水彩**的填色用 `brush.fill()` + `fillBleed()`（往外渗）+ `fillTexture()`；颜色比轮廓大一点、错开一点，有的地方涂出线、有的地方露纸；最后整个画面用 multiply 叠一层纸纹
- **动起来**：线条一秒抖 12 次（boil，像手画），**填色不抖**（填色跟着换种子会一闪一闪）；角色动作按关键帧补间
- **慢**：一帧零点几秒，走渲染路线 B（`render.md`）
- **颜色坑**：p5.brush 的颜色像颜料会混色，浅色叠在深蓝上会变绿。夜里的灯光、光晕用加色的方式最后叠上去（Canvas 2D 的 `globalCompositeOperation = 'lighter'`），别用浅色笔刷去「涂亮」；大的光晕会把浅色墙冲白，光柱画在角色后面
- **适合**：抒情、温暖、讲故事的歌
- **不是**：扁平矢量图加一层颗粒。轮廓要有笔触的轻重和颗粒，填色是排线或者有纹理的涂色，有的地方涂出线一点
- 示范：`examples/crayon/scene.html`

## 4. 纸艺立体书（papercraft diorama / paper cutout）

- 每样东西是一张硬纸片，外面一圈白边、一圈细的深色刀口线，能看出一点纸的厚度
- 纸片一层层前后站开，每层往后面那层投一块软影子
- 平涂上色，立体的东西分亮暗两面，可以撒些小彩点
- 浅景深：只有角色那一层清楚，背后的房间和前景都糊掉
- 暖色台灯光；动起来一秒 12 张，像定格动画

**画法**（Canvas 2D 合成）：
- 每张纸片画一次，缓存成离屏画布；外扩一圈暖白当白边，外面一圈细深色线当刀口，右下多露 2–3 px 深一点的颜色当纸厚
- 6–8 层前后摆开，每层往后一层投一块往右下的软影子（灯在左上）
- 每层一个模糊量（`ctx.filter = 'blur(…px)'`）：最远的房间约 20 px、后排 2–3、前排 1、角色 0、最前的草丛约 10
- 整个画面叠一层左上来的暖光，背景里糊掉的台灯光斑
- 动起来一秒 12 张、每张停两帧；每张纸片每张有一点点手摆的偏移，亮度轻微闪；镜头很慢地推近 5–7%，近的层放大得多（视差）

搜参考、写提示词用的英文关键词：papercraft diorama、paper cutout、tilt-shift / shallow depth of field、stop motion。

- **不是**：一张平面画加模糊。要真的分层站开、互相投影、近大远小地视差
- 示范：`examples/diorama/scene.html`

## 用户说了别的风格

先用三四条说清这个风格的特征（像上面「纸艺立体书」那样），按特征写画法，画一张样图确认。拿不准就请用户给一张参考图，或者一段视频（走 `learn-style.md`）。
