# 学一支视频的风格

用户刷到一支喜欢的视频，录下来放进文件夹（`reference.mp4`），想照它的风格做。在第 2 步之前做，结果写进 `style.md`，第 2 步起按它来。

**只学能迁移的规律**：配色、画法、节奏、转场、字怎么出。不搬它的画面、角色、故事。

## 步骤

1. **裁边**：录屏常带黑边、播放条、水印。先抽一张看：`python3 <skill>/scripts/contact_sheet.py reference.mp4 --every 5 -o review/ref-overview.jpg`，量出画面的范围（宽:高:x:y），后面的命令都加 `--crop`
2. **音乐**：`python3 <skill>/scripts/analyze_song.py reference.mp4 -o ref-analysis.json`（BPM、第一拍）
3. **节奏**：`python3 <skill>/scripts/video_rhythm.py reference.mp4 --crop 宽:高:x:y --analysis ref-analysis.json -o review/ref-rhythm.json`，得到每个镜头停多久、切点卡不卡拍、几拍一换
4. **看画面**：
   - 全片每 0.5 秒一格看整体：`contact_sheet.py reference.mp4 --crop … --every 0.5 -o review/ref-sheet.jpg`
   - 细节每秒 10 格逐页看（`--every 0.1`，会拆成好几张）；转场处逐帧看
   - 切点以 `video_rhythm.py` 量出来的为准，再看图确认。别按 0.5 秒抽帧估节奏，会估错（做过：估成「0.5–1 秒一张」，逐帧量出来能看清的画面都停 0.7–3 秒）
5. **写 style.md**（下面的结构）
6. **做完新片对照**：同一段落两边各抽几帧放一起比（`--start --end --every 0.25`），列出节奏、构图上的差距，逐条改

## style.md 的结构

```markdown
# 风格：<一句话概括>

## 声音
BPM、几拍换一个画面、切点有多少卡在拍上

## 配色
5–8 个 HEX，各用在哪（底、主体、强调、字）

## 画法
角色怎么画（线条、填色、占画面多大、常用的景别：大脸特写、背影当前景……）；背景怎么画；纹理

## 节奏和运镜
镜头停多久（平均、中位、最短最长）；短于 0.5 秒的用在哪；镜头里怎么动

## 转场
用到的几种，各几次，怎么接

## 画面里的字
字体、颜色、描边、多大、什么时候出、怎么出、和歌词什么关系

## 照着做要注意
最容易学不像的几处

## 量出来的规律
（直接列数字）
```

## 坑

- 「快」不是在长镜头上闪贴图：参考片的快是每个画面都是故事的下一步，能看清的画面照样停够时间
- 拼贴画面要和歌词、故事直接相关，同一张图不重复用
- 不套现成的风格模板，风格从片子本身推（抽帧、取色、量节奏）
