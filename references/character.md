# 角色

主角写成一个单独的代码文件 `character.js`，每个镜头都从这里取。这样造型、比例、颜色前后一致，不会每个镜头重新画一只，越画越走样。

## 接口（照这个写，名字可以改）

```js
// character.js：主角是<一句话描述>
// draw(g, o)：g 是画布（Canvas 2D 的 ctx，或者 p5 实例 p）
//   o.x, o.y      脚底中点的位置（世界坐标）
//   o.size        身高（像素）
//   o.facing      'front' | 'left' | 'right' | 'back'
//   o.expression  'happy' | 'shy' | 'sad' | …（按故事要的加）
//   o.action      'idle' | 'walk' | 'jump' | 'hug' | 'hold' | …
//   o.u           这个动作进行到哪，0→1（由分镜的时间算出来）
//   o.t           全片时间（呼吸、眨眼这种一直在的小动作用）
//   o.hold        拿着的道具：{ draw(g, hand) }，画在手上
// handAt(o, 'left' | 'right') → { x, y, angle }：手在哪，道具照这个画
```

## 规矩

- **纯函数**：只看参数，不存状态；随机数用固定种子（角色名 + 部位）
- **一直在动**：站着也有呼吸（身体上下 1–2%）、眨眼（每 3–5 秒一次，按 t 算）
- **姿势之间补间**：手臂角度、身体倾斜、挤压拉伸这些数值一律插值过渡，表情、朝向这类才直接换。不要写 `t < x ? 举手 : 放下`，那样会一帧跳过去
- **反应要大**：吃惊、开心有预备 → 到位 → 回弹；跳有挤压拉伸；难过会塌下去
- **道具拿稳**：用 `handAt()` 算出手的位置再画道具，跟着手走；换朝向、走起来也照手画，不留在原来的固定位置。抱在怀里的放在嘴下面；两只手拿的东西（围巾、毯子）两头搭在两只手上；道具不挡脸
- **够大**：交代环境的中景，角色占画面高度 20–28%；情绪点推到近景，35–50%。脚在歌词区上面
- **两个主角**：颜色加一个配饰区分（比如一只戴蝴蝶结），一眼分得开
